# AKML SQL workspace context

For project work, read [PROJECT_MEMORY.md](PROJECT_MEMORY.md) and
[CLAUDE.md](CLAUDE.md) first. The existing project principles and workflow are in
[.specify/memory/constitution.md](.specify/memory/constitution.md).

PROJECT_MEMORY.md is a source-backed orientation prepared on 2026-10-05 at the
owner's request, with particular attention to the AKML web application/engine and
SSMS plugin screens. It records architecture, entry points, documentation caveats,
recent changes, and verification guidance. It is a dated reference, not a claim
that the current checkout or installed application has been tested.

Before changing a feature, recheck its current implementation and the relevant
specification, tests, and latest progress entry. Update the memory when subsequent
work materially changes a recorded fact. Preserve unrelated working-tree edits
and follow the repository's explicit-consent rules for Git mutations.
