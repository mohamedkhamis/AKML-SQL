### What worked (web)

- **Pairing:** "Use this computer's engine" paired in one click, no PIN (status pill Live, Engine 1.26.1027.1505). Status bar, title and schema header follow the tab's connection; a new tab inherits the active connection, and the Connect dialog opens on the tab it connects.
- **Connect to database:** database list for Windows authentication (`Northwind_AutoTest`, `master`, `msdb`, `tempdb`) with the hint about the engine's account; PostgreSQL form with host/port/user/password, database list with refresh, TLS mode, "remember on the engine machine" with its warning.
- **Execution (SQL Server):** F5 runs (no browser reload); two statements → two stacked result sets ("7 rows · 58 ms"); GO batches with an error in batch 2 keep batches 1 and 3 (`Msg 8134, Level 16, State 1, Line 1 Divide by zero error encountered.`); clicking the error jumps to its line (Ln 3); Cancel stops `WAITFOR DELAY` in ~170 ms; the open-transaction prompt really rolls back (verified).
- **Execution (PostgreSQL):** one command per statement; an error in statement 3 of 4 keeps 1 and 2 with "SQLSTATE 22012: division by zero – 2 of 4 statements ran. Earlier statements stay applied unless they ran inside an explicit transaction."; computed result sets are read-only with the reason shown; `timestamptz` and booleans read as psql shows them; Cancel stops `pg_sleep` in ~285 ms.
- **Grid:** click/Shift+Arrow selection; Ctrl+C and Copy with headers put TSV on the clipboard (`CustomerName<TAB>ContactName` …); double-click or typing edits; `7.25` → `7.2500` (money), dates, Ctrl+0 → NULL; Apply writes all rows atomically and re-runs the query ("Applied 3 change(s)"), verified in both databases.
- **Explorer:** Tables/Views/Procedures/Functions counts; a table created outside the app appeared after the next refresh; right-click menu (Select Top 1000 Rows / Select first 1000 rows, Script as SELECT/INSERT/UPDATE/DELETE, Insert name, Copy name, Refresh) opens a new tab on the same connection and runs it (`SELECT TOP (1000) …` / `… LIMIT 1000;`).
- **Documents and history:** Save as asks for a name and downloads `name.sql` as UTF-8 with BOM, the tab takes the name; History groups by query session (`query-02 · ×5 · 5 versions`), the preview shows the SQL and Open puts it in a new tab on its connection.
- **Settings/theme:** Dark and High contrast apply immediately and persist in `localStorage['akml.theme']`; Snippets, Format styles (engine styles + built-ins, live preview "Preview updated · 61 ms") and Settings sections render without console errors.

### Not bugs

- `B''s Beverages`, `Bon app''`, `Let''s Stop N Shop` in the grid: `Northwind_AutoTest` really stores the doubled quote (`LEN(CustomerName) = 14` for row 11); the grid shows the value as stored.
- `COUNT ( * )`, `( c.City IN ( 'London' ) )`, tab indentation and `… ;` with a space come from Khamis Style's own settings (space inside parentheses, "Use tabs where possible", "Space before" semicolons), as in the last round.
- ST006 ("unnecessary square brackets") appears in the web Problems list although the user's SSMS `config.json` disables it: the SSMS overrides do not apply to the web edition (which has its own Settings › Code analysis). Where the analyser ran for this page (engine or in-browser) was not verified.
- "Tables (9)" right after `CREATE TABLE` from sqlcmd: external DDL is picked up on the 300 s poll or the next refresh; it showed as "Tables (10)" a minute later.
