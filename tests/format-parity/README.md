# Format Parity Corpus

Test corpus + golden outputs that drive SC-007 — "AKML-SQL's formatter produces output that matches SQL Prompt's output for ≥ 95 % of a 200-file representative corpus".

## Match definition (SC-007 / Q1 clarification)

For each `(corpus.sql × style.sqlpromptstyle)` pair, the test driver compares AKML output to the golden output as follows:

1. Strip trailing whitespace per line
2. Normalise line endings to `\n` (LF)
3. Drop UTF-8 BOM if present
4. **Then require byte-exact equality**

A pair passes iff the two normalised byte streams are equal. The suite passes iff ≥ 95 % of pairs pass.

## Populating the corpus

Populating `corpus/`, `styles/`, and `golden/` requires:

- A machine with **Redgate SQL Prompt installed**, so the golden outputs can be generated by SQL Prompt itself
- A curated set of SQL files exercising every setting group documented in `doc/SQL-PROMPT/SQL-Prompt-Features/SQL_Prompt_Features_Core.md §2.3`
- A small set of representative `.sqlpromptstyle` files (Redgate built-ins + a handful of real-world team styles)

The `scripts/assemble-corpus.ps1` script (task T071 in `specs/020-sqlprompt-visual-parity/tasks.md`) drives the generation. Results are checked into the repo so CI runs without needing SQL Prompt installed.
