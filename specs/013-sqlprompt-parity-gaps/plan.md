# Implementation Plan: SQL Prompt Parity — Remaining Gaps

**Branch**: `013-sqlprompt-parity-gaps` | **Date**: 2026-04-03 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/013-sqlprompt-parity-gaps/spec.md`

## Summary

Close the remaining gaps between AKML-SQL and RedGate SQL Prompt across 4 areas: UI/Color accuracy (Options dialog, IntelliSense icons), Formatting commands (Unformat, formatting region directives), SQL History enhancements (advanced search, match highlighting, rename), and Environment/Installer improvements (tab color propagation, silent install, style import). Research revealed that several features already have partial or full implementations — the work is primarily wiring, configuration, and hex value updates rather than greenfield development.

## Technical Context

**Language/Version**: C# / .NET Framework 4.7.2 (shell extensions), .NET 10 (engine)  
**Primary Dependencies**: VS SDK (15.9.3–17.14.x), MessagePack, SQLite + FTS5, Serilog, WPF  
**Storage**: SQLite (history), JSON files (config, profiles), %AppData%/AKML SQL/  
**Testing**: xunit 2.x, Microsoft.NET.Test.Sdk 17.x  
**Target Platform**: Windows (SSMS 20/21/22, VS 2019/2022/2026)  
**Project Type**: Visual Studio extension (multi-target shared project pattern)  
**Performance Goals**: Unformat <200ms, History search <500ms for 10K+ entries, Status bar update <200ms  
**Constraints**: .NET Framework 4.7.2 API surface for shell, no XAML (code-only WPF), VSCT per-target  
**Scale/Scope**: 10 user stories, ~15 files modified, ~3 new files

## Implementation Phases

### Phase A: UI/Color Accuracy (US1, US2) — No Dependencies

**Scope**: Update hex values and badge rendering. Pure visual changes, no architectural impact.

**US1 — Options Dialog**:
- File: `SettingsWindow.cs`
- Change: Update `ThemeBrushSet.Light` and `ThemeBrushSet.Dark` static constructors
- Light: Main #F5F5F5→#F0F0F0, Selected #CCE8FF→#0078D4 (white text on selection), Border #E0E0E0→#CCCCCC
- Dark: Main #1E1E1E→#2D2D3B, Panel #2D2D30→#1E1E2E, Text secondary #888888→#8892A8, Border #3C3C3C→#3A3F4E

**US2 — IntelliSense Icons**:
- File: `CompletionItemModel.cs` — Update `GetColor()` switch to SQL Prompt palette (see data-model.md for full mapping)
- File: `AkmlCompletionPopup.cs` — Modify `CreateItemVisual()`:
  - Badge background: semi-transparent (20% opacity of text color) instead of solid
  - Badge text: use the SQL Prompt text color instead of white
  - Badge dimensions: keep 18×16px, 2px corner radius

### Phase B: Formatting Commands (US3, US4) — No Dependencies

**Scope**: Wire existing engine operations to shell commands and extend directive recognition.

**US3 — Unformat Command**:
- `PackageGuids.cs`: Add `CmdUnformat = 0x0220` (next available in formatting group)
- NEW `UnformatCommand.cs`: Copy pattern from `FormatDocumentCommand.cs`, send `FormatActionRequest` with `ActionType = FormatActionType.Unformat (17)`. Support selection-only via `FormatSelectionRequest`.
- VSCT files (all 6 targets): Add button in AkmlSqlFormatGroup, keyboard shortcut Ctrl+B, Ctrl+U (matches SQL Prompt)
- Command Palette: Register "Unformat Document" / "Unformat Selection"

**US4 — Formatting Region Directives**:
- `NoformatScanner.cs`: Extend the regex patterns to match:
  - `-- AKML formatting off` / `-- AKML formatting on`
  - `-- SQL Prompt formatting off` / `-- SQL Prompt formatting on`
  - Keep existing `-- noformat` / `-- endnoformat` support
  - Case-insensitive matching
- Tests: Add test cases for all 3 syntax variants plus mixed usage

### Phase C: History Enhancements (US5, US6, US7) — Ordered

**US7 — Rename** (already implemented): Verify `name:` prefix search finds renamed queries. If not, add `tab_title` to FTS5 index or add SQL `WHERE tab_title LIKE` clause.

**US5 — Advanced Search Syntax** (depends on US7 verification):
- `HistorySearchParser.cs`: Extend tokenizer to detect:
  - Wildcards: `term*`, `*term`, `t?rm` → translate to FTS5 prefix syntax or LIKE patterns
  - Boolean: `OR` keyword between terms → pass through to FTS5
  - Boolean: `NOT` before term → FTS5 `NOT term`
  - Exact phrase: `"quoted text"` → FTS5 `"quoted text"`
  - CamelCase: short uppercase tokens (≤4 chars, all uppercase) → flag for post-filter
- `HistoryDatabase.SearchAsync`: Remove the literal quote wrapping (`"\"" + sanitized + "\""`) — pass parsed FTS5 query string directly
- Post-filter: Apply CamelCase matching on returned results using `CompletionItemModel.MatchesCamelCase()` logic (extract to shared utility)

**US6 — Search Match Highlighting** (depends on US5):
- `HistoryToolWindowControl.cs` → `UpdatePreviewWithHighlighting()`:
  - Parse search text into individual highlight terms (split by OR, strip NOT, extract quoted phrases)
  - Highlight each term independently with Yellow Ochre #F9A825 at 30% opacity
  - Handle wildcard patterns by expanding to matched text regions

### Phase D: Environment & Installer (US8, US9, US10) — Independent

**US8 — Tab Color Propagation**:
- `TabColoringManager.cs`: Implement the TODO stubs:
  - Status bar: Walk visual tree from `DTE.ActiveWindow` to find SSMS status bar element, apply color as Background brush
  - Floating window: Hook `IVsWindowFrameEvents` for undocked windows, apply 3px `BorderBrush` to window chrome
  - Defensive: Wrap all visual tree walking in try/catch — SSMS internal structure varies by version

**US9 — Installer Silent Mode**:
- `AkmlSqlSetup.iss`:
  - Add `AppMutex=Ssms.exe` directive in [Setup] section
  - Document `/LOG` flag (already supported by Inno Setup natively)
  - Add `CloseApplications=yes` and `CloseApplicationsFilter=*.exe` for graceful close prompt

**US10 — SQL Prompt Style Import**:
- `AkmlSqlSetup.iss`: Add post-install Pascal Script function:
  - Check `ExpandConstant('{localappdata}\Red Gate\SQL Prompt')` exists
  - If found, show checkbox "Import SQL Prompt settings"
  - If accepted, invoke engine with import request (or shell script wrapper around SqlPromptImporter)
  - `SqlPromptImporter` already handles 99-option mapping — just need the installer trigger

## Key Risks

| Risk | Mitigation |
|------|-----------|
| SSMS status bar visual tree varies across versions | Wrap in try/catch, graceful no-op on failure |
| FTS5 query injection via user search input | Sanitize special FTS5 chars; parameterize non-FTS clauses |
| Badge color readability with semi-transparent backgrounds | Test all 12 colors against dark popup background |
| NoformatScanner regex complexity with 3 syntax variants | Keep patterns simple; test with existing test suite |
| SQL Prompt import during install may fail silently | Log all import results; surface summary to user post-install |
