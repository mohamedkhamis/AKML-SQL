# Codebase map: web edition hosting (plan input)

**Branch**: `045-web-standalone-hosting` | **Date**: 2026-10-26 | **Spec**: [spec.md](./spec.md)

Made at plan time. Four read-only mappers covered the engine bridge, the web app, the installer
and platform facts, and each map was then re-checked by an independent verifier. This file keeps
the facts that survived verification, with the verifiers' corrections applied. Line numbers refer
to the `043-web-query-tabs-polish` tip that `045` was branched from. "Live" means the fact was
observed on the owner's workstation on 2026-10-26.

## 4. Platform facts used by the plan

| # | Fact | Evidence |

| P1 | WebAssembly streaming needs `application/wasm`; RFC 9239 makes `text/javascript` the JavaScript type. With `nosniff`, a wrong type for `.js`, `.css` or `.wasm` fails the load. | MDN `instantiateStreaming`; RFC 9239 |
| P2 | CSP3 `'self'` matches ws/wss on the same host and port; browser support for that is uneven. The IIS CSP already lists `ws://localhost:*`, `ws://127.0.0.1:*` and `wss:`, so reusing it does not depend on `'self'`. | W3C CSP3 §6.7.2.8; Firefox bug 1345615; WebKit bug 235873 |
| P3 | A delayed-auto-start service has "no specific time guarantee" and starts at the lowest thread priority. Auto-start services start at boot, before sign-in. | `SERVICE_DELAYED_AUTO_START_INFO` (Microsoft Learn) |
| P4 | `netsh advfirewall … delete rule name=` deletes all matches. A netsh rule's `name=` becomes its DisplayName, and its Name is a GUID. | netsh help (live); `New-NetFirewallRule` docs |
| P5 | Chromium does not cache responses that arrive with a certificate error, so until `bridge.cer` is trusted, every LAN load downloads the full 26 MB again (this is true of IIS LAN HTTPS today too). | https://codereview.chromium.org/725573004 |
| P7 | Uninstaller flags: `/SUPPRESSMSGBOXES` "only has an effect when combined with /SILENT and /VERYSILENT". Plain `MsgBox` is never suppressed. Code can test `UninstallSilent`. | Inno help (`topic_uninstcmdline`, `SuppressibleMsgBox`) |

| P6 | Windows naming hazards: reserved device names stay reserved with any extension; a trailing `.` or space is stripped; `:` marks an alternate data stream; 8.3 aliases (`WEB~1.CON`) exist. | Microsoft Learn "Naming Files, Paths, and Namespaces" |
