A FEW USEFUL ANSWERS

Before you start.

Is AKML free?

AKML is MIT-licensed and free to use. Your chosen AI provider may charge separately for its service.

Can I use PostgreSQL inside SSMS?

AKML's PostgreSQL workflow is in the browser edition with a compatible connected engine. The SSMS 22 extension is for SQL Server.

Does the browser edition need an engine?

Database connections and query execution require the engine. PostgreSQL language services also require it. SQL Server formatting and analysis can run locally in the browser.

Do I need to use AI?

No. Completion, formatting, analysis and SQL history provide useful workflows without configuring an AI provider.
